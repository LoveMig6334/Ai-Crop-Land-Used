# Technology Stack

## Core Languages & Runtimes
- **Python 3.12+:** The primary programming language for data processing, model development, and the web interface.

## Machine Learning & AI
- **PyTorch:** Used for building and training LSTM and Transformer-based deep learning models.
- **statsmodels & statsforecast:** Utilized for implementing ARIMA and other statistical forecasting methods.
- **scikit-learn:** Employed for data preprocessing (e.g., scaling) and model evaluation metrics.

## Data Processing & Analysis
- **pandas:** The core library for data manipulation, cleaning, and time-series analysis.
- **numpy:** Used for efficient numerical computations and array operations.

## Visualization
- **matplotlib:** The primary library for generating static charts and trend visualizations for reports and analysis.

## Web & API
- **Flask:** The lightweight web framework used for the application's dashboard and API development.

## Development Tools
- **Jupyter Notebooks:** The primary environment for interactive model development, experimentation, and data visualization.
- **Virtual Environment (.venv):** Used for dependency management to ensure project isolation and reproducibility.
